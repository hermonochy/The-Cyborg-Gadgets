# Server 5.0

Server 5.0 is the first non-watch gadget in the project. Unlike the watches, it prioritizes robust Wi‑Fi connectivity and data throughput over compact form factor. The device consists of an ESP32‑C3 paired with an SD card module, serving as a centralized hub where all data from every gadget—including text files, images, audio tracks, etc.—is stored. It is housed in a small enclosure designed to be carried conveniently in a bag or pocket. It also periodically broadcasts Bluetooth beacons to alert nearby cyborg gadgets of the user's presence.
